## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-request-account`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>

</td>
<td>

</td>
</tr>

<tr>
<td>

`android-account:deny-request-account`

</td>

</td>
</tr>

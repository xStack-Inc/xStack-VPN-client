# xStack VPN

`xStack VPN` - корпоративный VPN-клиент для безопасного доступа к внутренним ресурсам компании xStack.

Приложение работает как обычная desktop-утилита: запускается в окне, показывает текущее состояние соединения и может продолжать работу в системном трее после закрытия окна.

## Что умеет приложение

- включает и выключает VPN-соединение через большую кнопку на главном экране;
- показывает статус: выключено, подключение, включено, отключение или ошибка;
- отображает выбранную локацию, IP-адрес, длительность соединения и объем трафика;
- работает в системном трее;
- может запускаться вместе с операционной системой;
- поддерживает русский и английский язык интерфейса.

## Установка на Windows

1. Скачайте установщик `xStack VPN` для Windows.
2. Запустите установщик.
3. Не меняйте путь установки, если администратор или инструкция компании не требуют другого.
4. Дождитесь завершения установки.
5. Запустите `xStack VPN` из меню `Start` или с ярлыка на рабочем столе.

Если Windows Defender SmartScreen показывает предупреждение:

1. Нажмите `More info`.
2. Проверьте, что название приложения - `xStack VPN`.
3. Нажмите `Run anyway`, если вы получили установщик из доверенного корпоративного источника.

Предупреждение может появляться у новых или неподписанных сборок. Это не обязательно означает, что приложение заражено, но запускать его нужно только из официального источника компании.

## Установка на macOS

1. Скачайте файл `xStack VPN.dmg` для вашей архитектуры Mac.
2. Откройте `.dmg` двойным кликом.
3. Перетащите `xStack VPN.app` в папку `Applications`.
4. Откройте `Applications`.
5. Запустите `xStack VPN`.

Если macOS показывает предупреждение, что приложение загружено из интернета или создано неизвестным разработчиком:

1. Нажмите `Cancel` или закройте предупреждение.
2. Откройте `System Settings`.
3. Перейдите в `Privacy & Security`.
4. Внизу страницы найдите сообщение о блокировке `xStack VPN`.
5. Нажмите `Open Anyway`.
6. Подтвердите запуск.

Если кнопка `Open Anyway` не появилась:

1. Откройте папку `Applications`.
2. Нажмите `Control + click` или правой кнопкой мыши по `xStack VPN.app`.
3. Выберите `Open`.
4. Подтвердите запуск.

## Первый запуск

При первом запуске приложение может спросить разрешение на отправку служебной корпоративной телеметрии.

Телеметрия может включать:

- версию приложения;
- операционную систему;
- архитектуру устройства;
- служебные события запуска и подключения;
- имя пользователя и имя компьютера;
- локальные IP-адреса;
- доменную информацию устройства, если она доступна.

Пароли, VPN-ключи и содержимое сетевого трафика не должны передаваться через этот механизм.

## Как подключиться

1. Откройте `xStack VPN`.
2. Нажмите кнопку `Включить`.
3. Дождитесь статуса `VPN включен`.
4. После подключения окно можно закрыть - приложение останется работать в системном трее.

Чтобы отключиться:

1. Откройте окно приложения или меню системного трея.
2. Нажмите `Выключить`.
3. Дождитесь статуса `VPN выключен`.

## Системный трей

После закрытия главного окна приложение не завершается, а остается в фоне.

В меню трея доступны:

- текущий статус VPN;
- `Открыть`;
- `Включить VPN` или `Выключить VPN`;
- `Выход`.

Чтобы полностью закрыть приложение, используйте пункт `Выход` в системном трее.

## Настройки

Откройте настройки через кнопку в правом верхнем углу приложения.

Доступные параметры:

- `Запускать вместе с ОС` - приложение будет стартовать после входа пользователя в систему;
- `Сворачивать в трей при закрытии` - окно закрывается, но приложение продолжает работать;
- `Автоматически подключаться после запуска` - VPN включается после старта приложения;
- `Язык интерфейса` - русский или английский;
- `Служебная телеметрия` - разрешение на отправку диагностических событий администратору компании.

Для обычного использования рекомендуется оставить путь установки и системные настройки по умолчанию.

## Частые вопросы

### Почему macOS или Windows показывает предупреждение?

Операционные системы могут предупреждать о новых приложениях, особенно если сборка еще не имеет репутации или не подписана коммерческим сертификатом разработчика. Используйте только сборки, полученные из доверенного корпоративного источника.

### Нужно ли запускать приложение от имени администратора?

Обычно нет. Если конкретная корпоративная инструкция требует запуск от имени администратора, следуйте ей.

### Почему приложение остается в фоне после закрытия окна?

Это нормальное поведение VPN-клиента. Соединение должно продолжать работать, даже если главное окно закрыто. Для полного завершения используйте `Выход` в системном трее.
